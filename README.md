Priston Tale — Arquivos para Servidor Próprio

Olá! 👋

Estou disponibilizando os arquivos necessários para você montar e configurar o seu próprio servidor de Priston Tale.

O projeto reúne os principais componentes necessários para colocar o servidor em funcionamento, incluindo:

Cliente completo — arquivos do cliente do jogo.

Servidor completo — arquivos e códigos necessários para o servidor.

Website — arquivos do site/painel para o servidor.

XAMPP — ambiente necessário para executar os serviços web e banco de dados.

Objetivo

A ideia deste projeto é disponibilizar uma base completa para estudos, desenvolvimento e criação de um servidor próprio de Priston Tale.

Os arquivos estão organizados para facilitar a instalação, configuração e personalização do projeto.

Observação: Antes de utilizar ou distribuir os arquivos, verifique os direitos autorais e as licenças aplicáveis aos arquivos, códigos, imagens e demais componentes incluídos no projeto.
